# The Visible Bible

The Bible in maps, charts and timelines — 66 books, ~3,000 people and ~1,200 places, in 16 languages.
Live at https://alexandermou.github.io/visible-bible/

Data: [Theographic Bible Metadata](https://github.com/robertrouse/theographic-bible-metadata) by Robert Rouse (CC BY-SA 4.0), the dataset behind [viz.bible](https://viz.bible). Created by Alexander Mou.
